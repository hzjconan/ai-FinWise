## 题目

### 题 1 · "我们每月 GPU 账单很高，你入职第一个月会怎么做？"（L07 第 6 步）

**答题框架**：量化 → 找最大头 → 按类出方案（等价 → 近似等价 → 有损）→ 红线验证 → 灰度上线 + 看板。

**参考回答**（约 1 分钟）：
1. **先量化**：拿账单按团队 / 任务拆开，同时接上利用率指标——GPU 分配率 vs 实际使用（DCGM）、MFU、排队时长、失败重跑次数。账单说明钱花在哪，指标说明浪费在哪。
2. **找最大头**：通常是三类——GPU **在等数据**（视频解码打满 CPU）、**占着不用**（闲置 notebook、调试任务独占整卡）、**白算**（失败后从头重跑、重复实验）；再加上**碎片**导致大任务排不上、被迫扩容。
3. **先做等价优化**：GPU 解码 / 离线预处理 / 预计算冻结特征 / 本地缓存；回收闲置、小任务用 MIG 共享；checkpoint + 断点恢复；装箱调度防碎片；可中断任务用低价资源。**再做近似等价**：BF16 等，需验证。降分辨率、换小模型这类**有损**方案只提出数据，和算法团队一起决定。
4. **质量红线不变**：沿用现有评估标准（离线指标 → 仿真 → 真机），A/B 只改一项、多随机种子。
5. **灰度上线**：先在部分队列 / 任务开启，看成本看板和质量指标，没问题再全量；随时可回滚。目标用**单位成本**汇报：每有效训练小时成本、MFU 提升多少。
