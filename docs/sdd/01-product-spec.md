# 理财产品推荐系统 — 产品规格说明书 v1.0

## 1. 产品概述

**产品名称**: FinWise（智财通）

**一句话描述**: 帮助用户评估自身风险偏好，并智能匹配适合的理财产品。

**核心价值主张**: 用户不需要具备专业金融知识，通过回答风险评估问卷，系统自动计算其风险偏好等级，并从已录入的理财产品中推荐最匹配的产品。

---

## 2. 用户角色

| 角色 | 描述 |
|------|------|
| **管理员 (Admin)** | 管理理财产品信息、维护风险评估问卷、查看系统数据 |
| **客户 (Customer)** | 浏览理财产品、完成风险评估、获取个性化推荐 |

---

## 3. 功能需求

### 3.1 管理员功能

#### F-A01: 理财产品管理
- **创建产品**: 输入产品名称、类型、投资方向、起投金额、投资期限、历史收益数据
- **编辑产品**: 修改已有产品信息
- **下架/上架产品**: 控制产品是否对客户可见
- **查看产品列表**: 分页浏览所有产品，支持按类型/风险等级筛选

#### F-A02: 历史收益数据录入
- 管理员为每个产品录入多期历史收益率数据（如月度/季度/年度）
- 系统根据历史数据自动计算：
  - **期望收益率** = 历史收益率的加权平均值
  - **风险等级** = 基于收益率标准差映射到风险等级（R1-R5）

#### F-A03: 风险评估问卷管理
- **添加题目**: 输入题目内容、选项列表、每个选项对应的分值
- **编辑/删除题目**: 修改已有题目
- **调整题目顺序**: 拖拽排序
- **预览问卷**: 以客户视角预览完整问卷

#### F-A04: 系统数据概览（Dashboard）
- 产品总数、各风险等级产品分布
- 客户总数、各风险偏好等级客户分布
- 近期评估完成量趋势

### 3.2 客户功能

#### F-C01: 浏览理财产品
- 查看所有上架产品列表（卡片/列表视图）
- 按类型、风险等级、期望收益率筛选和排序
- 查看产品详情页：产品信息、收益走势图、风险等级标识

#### F-C02: 风险评估（两阶段）

**阶段一 — 固定问卷（MVP）**:
- 完成风险评估问卷（逐题作答）
- 系统根据总分映射为风险偏好等级（C1保守型 ~ C5激进型）
- 展示评估结果及解读说明
- 支持重新评估

**阶段二 — AI 对话评估（后续迭代）**:
- 与 AI 机器人进行自然语言对话
- AI 主动提问，动态调整问题方向
- 约 5-8 轮对话后 AI 给出风险偏好等级
- 展示评估结果 + AI 评估依据摘要
- 两种模式共存，客户可自选

#### F-C03: 智能推荐
- 根据客户风险偏好等级匹配产品风险等级
- 推荐策略：
  - **精确匹配**: 风险等级完全一致的产品
  - **相邻推荐**: 上下一级风险等级的产品（标记为"稍保守"/"稍激进"）
- 按期望收益率排序展示推荐结果
- 未完成评估时提示先完成评估

#### F-C04: 个人中心
- 查看评估历史记录
- 当前风险偏好等级
- 收藏的产品列表

#### F-C05: 客户注册与登录（阶段二）

**匿名访问（阶段一已支持）**:
- 首次访问时系统自动创建匿名客户身份（分配 customer_code）
- 匿名状态下可浏览产品、完成评估、收藏产品
- 数据通过 customer_code 关联，存储在服务端

**注册（阶段二）**:
- 匿名客户可选择注册，绑定用户名和密码到已有客户记录
- 注册后匿名期间产生的数据（评估记录、收藏）无缝保留
- 用户名仅用于登录认证和页面展示，不作为 API 标识

**登录（阶段二）**:
- 已注册客户使用用户名 + 密码登录
- 登录后返回对应的 customer_code，恢复所有历史数据
- 支持在不同设备间登录访问同一账户

## 4. 风险评估模型

### 4.1 产品风险等级计算

输入：产品的 N 期历史收益率 [r1, r2, ..., rn]

```
期望收益率 E = Σ(ri) / n
收益率标准差 σ = sqrt(Σ(ri - E)² / (n-1))
变异系数 CV = σ / |E|  （当 E ≠ 0 时）
```

风险等级映射：

| 风险等级 | 标签 | 标准差 σ 范围 |
|---------|------|--------------|
| R1 | 低风险 | σ < 1% |
| R2 | 中低风险 | 1% ≤ σ < 3% |
| R3 | 中风险 | 3% ≤ σ < 8% |
| R4 | 中高风险 | 8% ≤ σ < 15% |
| R5 | 高风险 | σ ≥ 15% |

### 4.2 客户风险偏好计算（两阶段演进）

#### 阶段一：固定问卷评估（MVP）

每道题有若干选项，每个选项对应一个分值（如 1-5 分）。

```
总分 S = Σ(每题所选选项分值)
归一化分 N = S / 最大可能总分 × 100
```

风险偏好映射：

| 偏好等级 | 标签 | 归一化分范围 |
|---------|------|-------------|
| C1 | 保守型 | N < 20 |
| C2 | 稳健型 | 20 ≤ N < 40 |
| C3 | 平衡型 | 40 ≤ N < 60 |
| C4 | 成长型 | 60 ≤ N < 80 |
| C5 | 激进型 | N ≥ 80 |

**特点**: 题目固定、流程简短、结果可预测，适合快速上线。

#### 阶段二：AI 对话式评估（后续迭代）

用 AI 聊天机器人替代固定问卷，通过自然对话评估客户风险偏好。

**交互流程**:
1. 客户进入评估页面，选择"AI 对话评估"模式
2. AI 主动发起第一个问题（由系统 prompt 控制开场）
3. 客户用自然语言回答，AI 根据回答动态调整后续问题
4. AI 在对话过程中持续评估，收集到足够信息后（约 5-8 轮对话）给出结论
5. AI 输出结构化评估结果：偏好等级（C1-C5）+ 评估依据摘要

**技术方案**:
- 后端集成 Claude API（Anthropic SDK）
- 系统 prompt 定义 AI 的评估框架和输出格式
- AI 需要评估的维度：
  - 投资经验与知识水平
  - 收入稳定性与可投资资金比例
  - 对亏损的心理承受能力
  - 投资目标与期限预期
  - 对收益波动的态度
- AI 输出格式约束（JSON）：
  ```json
  {
    "risk_level": "C3",
    "confidence": 0.85,
    "summary": "基于您的回答，您具备一定投资经验...",
    "dimensions": {
      "experience": 3,
      "loss_tolerance": 2,
      "income_stability": 4,
      "investment_horizon": 3,
      "volatility_tolerance": 3
    }
  }
  ```
- 对话历史存储，支持审计和模型优化

**与阶段一的兼容**:
- 两种评估模式共存，客户可自由选择
- 输出统一为 C1-C5 偏好等级，推荐匹配规则不变
- 评估记录统一存储，标记来源（questionnaire / ai_chat）

### 4.3 推荐匹配规则

| 客户偏好 | 精确匹配产品 | 相邻推荐产品 |
|---------|-------------|-------------|
| C1 | R1 | R2 (稍激进) |
| C2 | R2 | R1 (稍保守), R3 (稍激进) |
| C3 | R3 | R2 (稍保守), R4 (稍激进) |
| C4 | R4 | R3 (稍保守), R5 (稍激进) |
| C5 | R5 | R4 (稍保守) |

## 5. 非功能需求

| 维度 | 要求 |
|------|------|
| **响应式设计** | 客户端 UI 适配移动端（≥ 375px）和桌面端 |
| **管理端** | 桌面端优先，最小宽度 1024px |
| **性能** | 页面首屏加载 < 2s，API 响应 < 500ms |
| **安全** | 管理员需登录认证；客户阶段一匿名使用，阶段二支持注册登录（JWT 认证） |
| **数据** | 支持 SQLite（开发）/ PostgreSQL（生产） |
| **测试** | 硬性要求：每次代码改动必须编写对应测试并确保已有测试通过 |

---

## 5.1 测试策略

**核心原则**: 测试是硬性要求，不可跳过。每次代码变更必须：
1. 为新增/修改的功能编写对应测试
2. 确保所有已有测试通过
3. 需求变更导致功能修改时，同步更新受影响的测试用例

### 后端测试（pytest）

| 测试类型 | 范围 | 说明 |
|---------|------|------|
| **单元测试** | 服务层 | 风险计算引擎、编码生成器等纯逻辑函数 |
| **集成测试** | API 路由 | 使用测试数据库，覆盖所有 API 端点的正常和异常路径 |

**覆盖要求**:
- 所有 API 端点至少覆盖：正常请求、参数校验失败、资源不存在
- 风险计算引擎：边界值（0条/1条/2条数据）、各等级阈值
- 认证：有效/无效/过期 Token

### 前端测试（Cypress E2E）

| 测试场景 | 说明 |
|---------|------|
| **管理员登录** | 正确/错误凭证、Token 持久化 |
| **产品管理** | 创建、编辑、上下架、收益录入 |
| **问卷管理** | 创建、编辑、删除题目 |
| **客户端产品浏览** | 列表、筛选、详情、收藏 |
| **风险评估** | 完整答题流程 → 结果 → 推荐 |
